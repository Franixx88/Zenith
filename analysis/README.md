# Zenith — локальная доска анализа

Двойной клик по **`start-analysis.cmd`** в корне проекта. Откроется
`http://127.0.0.1:8765` в браузере. Повторный запуск открывает уже работающую
сессию. При первом запуске отсутствующий release-движок собирается Cargo.

Используется настоящий `target/release/zenith.exe` через UCI: по умолчанию
**8 потоков, 128 МБ общей TT, неограниченный анализ**, автоматические локальные
Syzygy из настроек самого движка. Поиск остаётся нативным, без WebAssembly
и лимитов браузерного движка. Скорость зависит от позиции и загрузки CPU.
Игровая оценка пока классическая; непроверенные SE/SMP voting по умолчанию
выключены, их можно включить в дополнительных настройках.

## Возможности

- Ходы кликами и перетаскиванием, подсказки легальных клеток, шах и последний ход.
- Оба цвета, рокировки, en passant, выбор всех четырёх превращений.
- Навигация по ходам и дерево вариантов без потери основного продолжения.
- Лучший вариант в SAN; клик по ходу переносит его последовательность на доску.
- Оценка за белых, мат, табличные победы `TB+`/`TB−`, глубина, NPS, узлы, tbhits.
- Стрелка лучшего хода и собственные стрелки/круги правой кнопкой.
- График оценок посещённых позиций в выбранной ветке; он не выдумывает оценки
  для непроанализированных ходов и не является автоматическим разбором партии.
- Импорт одной партии PGN с вариантами или FEN; экспорт PGN, копирование FEN.
- Потоки, хеш, Syzygy и параметры поиска; пауза и очистка TT/историй.
- Локальное сохранение партии, курсора и настроек в `runs/analysis/session.json`.
- Адаптивная настольная/узкая компоновка, всё работает без внешних CDN.

Клавиши: **← / →** — предыдущий/следующий ход, **Home / End** — начало/конец,
**F** — переворот, **A** — стрелка движка, **Space** — пауза,
**?** — помощь. Клавиши не перехватываются в полях ввода.

Поток `info` обрабатывается с номером ревизии: оценка старой позиции не может
перезаписать новую. Передаётся полная история ходов, включая корневой FEN;
повторения и правило 50 ходов учитываются. Есть одна общая сессия на порт:
две вкладки видят одно дерево. Для независимой доски нужен другой порт и
`--no-save`, чтобы не писать в общий файл сохранения.

Когда вкладки закрыты/соединение потеряно, поиск автоматически останавливается
после истечения 15-секундной аренды (с учётом heartbeat — обычно до 20 секунд).
При открытии вкладки возобновляется. Явная пауза сохраняется в открытой сессии.
`Ctrl+C` в консоли завершает сервер и движок. На Windows дочерний движок
прикреплён к Job Object с `KILL_ON_JOB_CLOSE`: даже аварийно завершённый сервер
не оставляет работающий поиск. Браузер к этому Job не прикрепляется.

MultiPV доступен в Zenith 0.12.0: выбери 1/2/3/5/8 линий в панели анализа или
1..32 в настройках. Это один многопоточный поиск с общим бюджетом и TT.
Больше линий означает меньшую глубину за то же время. По умолчанию выбрана
одна линия; экспериментальное голосование SMP работает только в этом режиме.
Клик по любому продолжению открывает его в дереве. [Детали](../docs/multipv-0.12.md).

## Ручной запуск / зависимости

Используется уже подготовленная `.venv-nnue`, PyTorch для доски не нужен.
Для чистого окружения:

```powershell
py -3 -m venv .venv-nnue
.venv-nnue/Scripts/python.exe -m pip install -r analysis/requirements.txt
cargo build --release --bin zenith
.venv-nnue/Scripts/python.exe analysis/server.py --open
```

Не пересоздавай существующее обучающее окружение. Можно использовать другое
окружение с этими двумя пакетами и запускать `analysis/server.py` его Python.

```powershell
.venv-nnue/Scripts/python.exe analysis/server.py --port 8766 --no-save --open
```

Сервер слушает только loopback. Запись проверяет Origin/Host и токен сессии;
произвольные shell-команды и исполняемые пути через веб-API не принимаются.
Путь к другому UCI-бинарнику задаётся только аргументом `--engine` при запуске.
PGN ограничен 512 КБ / 4096 узлами / 2048 полуходами в линии, используется
стандартный шахматный режим. `--no-save` отключает восстановление/запись сессии.

## Проверки

```powershell
node --check analysis/static/app.js
.venv-nnue/Scripts/python.exe -m unittest discover -s analysis -p test_server.py -v
```

Проверяются атомарность нелегальной PV/импорта, варианты и история, специальные
ходы, сохранение/восстановление курсора, знак оценки за белых, отбрасывание
устаревшей информации, HTTP/Origin/CSRF, настоящий UCI-поиск, отмена, повторения
и уничтожение дочернего процесса при аварийном закрытии Windows-родителя.
В браузере проверены клики, перетаскивание, ветвление, FEN и выбор недопревращения.
Также проверены пауза, выполнение найденного хода на паузе и настоящий
табличный выигрыш KBNK с `TB+`/ненулевым tbhits. 14 тестов адаптера проходят;
нативный тест проверяет остановку по истечению аренды браузера и возобновление.
