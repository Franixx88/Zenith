# Third-party material

`arrayvec` 0.7.8 is used through its safe API for inline fixed-capacity move
buffers with an initialized prefix. Copyright (c) Ulrik Sverdrup "bluss"
2015–2023. Dual license: MIT OR Apache-2.0. License texts are preserved in
`docs/licenses/arrayvec-MIT.txt` and `docs/licenses/arrayvec-APACHE.txt`.
Source/documentation: https://docs.rs/arrayvec/0.7.8/arrayvec/.

`shakmaty` 0.30.2 and `shakmaty-syzygy` 0.28.1 by Niklas Fiekas are used
for the endgame position adapter and Syzygy probing. Both are GPL-3.0-or-later,
covered by the root `LICENSE`. Syzygy probing credits Ronald de Man and is
closely based on his Stockfish implementation. Sources and documentation:
https://github.com/niklasf/shakmaty and https://docs.rs/shakmaty-syzygy/.
The optional mmap feature is disabled; Zenith uses safe file-backed probing.
Locked transitive dependencies and their preserved notices are listed in
`docs/licenses/dependencies-0.10.md`. Normal move generation remains Zenith's.

The optional tiny test-table downloader fetches ten three-piece WDL/DTZ files
from https://tablebase.lichess.ovh/tables/standard/ (Syzygy tables by Ronald
de Man). SHA256 hashes and URLs are recorded in `tools/syzygy-test-manifest.json`.
The binary tables live in ignored `target/syzygy-tests`, not in the source tree.

`tools/download_syzygy.mjs` additionally downloads the complete standard 3–5
piece WDL+DTZ set (290 files, Ronald de Man's Syzygy tables) to ignored
`syzygy/3-4-5`. File sizes and published SHA256 hashes from
https://tablebase.lichess.ovh/tables/standard/sha256 are pinned in
`tools/syzygy-3-4-5-manifest.json`. The binary tables are not bundled with the
source or compiled executable.

`src/eval/psqt.rs` adapts the piece-square parameter tables from Stockfish 15,
`src/psqt.cpp`, tag `sf_15` (2022).

Copyright (C) 2004–2022 The Stockfish developers. Authors are preserved in
`docs/stockfish-authors.txt`.

Source: https://github.com/official-stockfish/Stockfish/blob/sf_15/src/psqt.cpp

License: GNU General Public License version 3 or, at your option, any later
version. The complete license is in `LICENSE`. Zenith is distributed under the
same license. Changes: translated the parameter layout to Rust, retained A1
orientation and file mirroring, and divided positional bonuses by two to fit
Zenith's material scale. Material values, evaluation terms and search are Zenith
implementations; this is not Stockfish's complete classical evaluator or NNUE.

Reckless and Chessprogramming were consulted for algorithm descriptions. No
Reckless source files or neural network weights are included.

Optional NNUE Python development tools use PyTorch, NumPy, PyArrow and
python-chess; pinned versions are in `tools/nnue/requirements*.txt`.
The environment is not bundled with the engine. Candidate binpack datasets
from `adamtwiss/t91-binpacks-filtered` and `official-stockfish/master-binpacks`
are listed with their repository revisions and reported ODbL license in
`tools/nnue/dataset-sources.json`; their binary data has not been downloaded.
No candidate's license is automatically substituted for another dataset's
license in training provenance. See `docs/nnue-training.md` for sources.

The optional process-isolated training adapter `tools/binpack` uses
`sfbinpack` 0.6.5 from https://github.com/Disservin/binpack-rust, revision
df32a6b22e28354c9f928cdedbe058336d3bb3fa (Rust port of the Stockfish binpack
reader), declared GPL-3.0. The adapter is distributed under GPL-3.0-only;
its complete license is `tools/binpack/LICENSE`. This dependency is separate
from the game engine. Its locked dependencies/notices are listed in
`docs/licenses/binpack-dependencies.md`.

`tools/binpack/tests/data/ep1.binpack` is the 46-byte test/ep1.binpack fixture
from that exact crate/revision, under the same GPL license. The expected
three FEN/move/score/ply records are independently fixed by upstream's
compressed_reader.rs test_reader_simple; they are not generated by our writer.
No reader source files were copied into Zenith; Cargo fetches the pinned crate.
One complete initial chunk of the ODbL T91 source was downloaded for compatibility
tests into ignored `target/binpack-samples`. It is a partial source file, not a
verified download of the full dataset. Its range, local checksum and source
revision are recorded alongside it and in `tools/nnue/dataset-sources.json`.

The optional match runner uses Disservin/Fastchess v1.8.2-alpha as an external
executable, downloaded from its official GitHub release by
`tools/install_fastchess.ps1`. Fastchess is MIT licensed; its complete notice is
`docs/licenses/fastchess-1.8.2-alpha-MIT.txt`. The installer pins the archive and
executable SHA-256. No Fastchess code is linked into Zenith. Root consensus and
singular-extension code are independent implementations of published chess
search techniques; no Stockfish/Reckless source was copied for these changes.

The local analysis board uses python-chess 1.999 / chess 1.11.2,
GPL-3.0-or-later, and bundles the CBurnett SVG chess pieces by Colin M. L.
Burnett, GPL-2.0-or-later, redistributed here under GPL-3.0-or-later (root
LICENSE). The 12 piece SVGs come from lichess-org/lila revision
90bed61054303db49fa7e7f4d48854f0afaaff32; source URLs and per-file checksums
are recorded in analysis/static/pieces/source.json. Upstream's COPYING.md
attributes public/piece/cburnett to Burnett under GPLv2+. No Lichess interface
source code is included. The board and UCI bridge are Zenith project code.

NNUE data source selected for future training:


Mateusz Grzyb, *Lichess Chess Positions: ML-Ready Deduplicated Evaluations*
(2025), https://huggingface.co/datasets/mateuszgrzyb/lichess-stockfish-normalized,
revision d83b3256d94a086f074a66db52f3a5b5d4c28847. Dataset license: CC BY 4.0,
https://creativecommons.org/licenses/by/4.0/. Original Lichess evaluation data:
https://database.lichess.org/#evals, CC0. One four-field FEN from the dataset
viewer is used as a rejected-input regression in tests/nnue.rs. No Parquet
shards or trained weights are bundled. Zenith's other NNUE test positions and
synthetic weights are arithmetic fixtures, not trained models.
