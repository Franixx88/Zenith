# История версий

## 0.13.0

Первая версия, зафиксированная в Git. Предыдущие этапы ниже восстановлены
по документации проекта; отдельных Git-снимков этих исходников нет.

- NNUE v1 подключена к UCI-поиску через `EvalFile` и `Use NNUE`.
- Ленивые i16-аккумуляторы каждого потока, AVX2/scalar, main/qsearch,
  null move, MultiPV и корректная смена моделей.
- Без файла сети работает классическая оценка. Обученной сети пока нет.
- Проверки на момент фиксации: 148 обычных Rust-тестов, 6 реальных Syzygy,
  14 Python-тестов; дополнительные release-проверки NNUE.
- Подробности: [интеграция NNUE](docs/nnue-search-0.13.md).

## 0.12.1 — этап до Git

- SEE на виртуальной занятости без временных Board, точный пороговый SEE
  и ленивая классификация взятий.
- Локальный `bench 8`: +16.2% NPS при неизменном дереве; это не измерение Elo.
- [Замеры и проверки](docs/see-speed-0.12.1.md).

## 0.12.0 — этап до Git

- Настоящий MultiPV 1–32 с общим бюджетом, SMP и Syzygy.
- Выбор нескольких линий в локальной доске анализа.
- [Алгоритм и проверки](docs/multipv-0.12.md).

## 0.11.0 — этап до Git

- Fastchess/SPRT, парные матчи и независимая валидация PGN.
- Экспериментальные singular extensions и SMP voting, параметры поиска.
- [Проверки и результаты](docs/engine-testing-0.11.md).

## 0.10.x и ранее — этапы до Git

- Lazy SMP, Syzygy, селективный поиск, генерация ходов и классическая оценка.
- Подготовка NNUE, AVX2, тренер и потоковое чтение Stockfish binpack.
- Исторические отчёты находятся в [docs](docs), партии — в [games](games).
