# Zenith v0.13.0

Первая публикация проекта в GitHub. Шахматный UCI-движок на Rust с Lazy SMP,
Syzygy, MultiPV и подключением собственной NNUE v1.

В этой версии нейросетевая оценка подключена к боевому поиску через
`EvalFile` / `Use NNUE`. Обученные веса не включены; без файла сети работает
классическая оценка. Текущий Elo не измерен.

Архивы релиза содержат самостоятельный UCI-движок для Windows x86-64 и
Linux x86-64, информацию о Git-коммите и SHA-256. AVX2 выбирается во время
работы; предусмотрен scalar fallback. Syzygy-таблицы и обучающие датасеты
скачиваются отдельно. Локальная доска анализа запускается из исходников.

В проверках разработки прошли 154 Rust-теста, включая 6 тестов реальных
Syzygy, и 14 Python-тестов. Обычная CI не скачивает полный набор таблиц и
большие обучающие данные; такие тесты остаются ignored с явными инструкциями.
