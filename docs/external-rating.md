# Внешняя оценка силы Zenith v3

Фиксируются бинарник ускоренного Zenith `12ce81e` и сеть
`576258170751e54bbf6c0e7729cbe432168fdbc474a27a4f67e1214a7f4891d9`.
Это оценка локального пула с привязкой к CCRL Blitz, а не официальный рейтинг
CCRL, FIDE или Lichess. Тестирование не меняет движок или его веса.

## Соперники и источник шкалы

В [конфигурации](../tools/rating-pool.json) сохранены выбранные версии,
рейтинги, опубликованные погрешности, число партий, release URLs, SHA-256
полученных бинарников и результаты UCI preflight.
Источник — [CCRL Blitz](https://computerchess.org.uk/404/rating_list_all.html),
снимок 27 октября 2026. Полный исходный HTML сохраняется локально с хешем.

Исходный пул: BBC 1.2 (1946), MinimalChess 0.6 (2439), Zahak 4.0 (2552),
Weiss 1.0 (2896), Topple 0.8.1 (3036), все 64-bit single-CPU записи.
Используются готовые неизменённые Windows-сборки из авторских GitHub releases.
Пути в target игнорируются Git; сетевые загрузки не выполняются контроллером.

CCRL использует контроль, эквивалентный 2m+1s на i7-4770K, и допускает
таблицы до 6 фигур. Наш контроль 10s+0.10s на Ryzen 5 2400G без таблиц.
Различие условий даёт систематическую неопределённость, которую невозможно
устранить простым увеличением числа партий на коротком контроле.

## Конечный план эксперимента

1. Пять разведочных матчей по 16 цветовых пар: 160 партий, 5s+0.05s,
   отдельные calibration-дебюты. Они не участвуют в расчёте рейтинга.
2. Четыре наиболее близких по счёту соперника получают по 96 цветовых пар:
   768 партий Zenith на holdout-дебютах, 10s+0.10s.
3. Шесть матчей выбранных соперников между собой, по 16 пар: ещё 192 партии
   на том же контроле, для связи локального рейтингового пула.
4. Ordo оценивает все 960 рейтинговых партий совместно. Опорный соперник —
   ближайший по разведочному счёту; его опубликованный рейтинг закрепляется.

Общий объём — 1120 партий, включая исключённую разведку. Threads=1,
Hash=128 MiB, concurrency=4, ponder off, собственные книги выключены,
Syzygy выключены, Context Histories=false. Общий предел одной попытки —
10800 секунд бодрствования системы. При необходимости готовые матчи можно
продолжить через --resume, сохранив прежние параметры и замороженные файлы.

Для старых однопоточных соперников стенд допускает отсутствие Threads=1,
Move Overhead и выключенного SyzygyPath только с --external-engines.
Все пропуски явно записываются. Hash остаётся обязательным; неизвестные
пользовательские опции и запрос нескольких потоков без Threads отвергаются.
Каждый PGN проверяется по легальности, терминальному результату и цветовым
парам; просрочки, обрывы и незавершённые серии не входят в рейтинг.

## Погрешность и проверка привязки

[Ordo 1.2.6](https://github.com/michiguel/Ordo/releases/tag/v1.2.6) рассчитывает
локальную шкалу из общего PGN, включая перекрёстные матчи. Записывается
обычная модельная погрешность с 2000 симуляциями. Дополнительно выполняются
1000 повторных оценок с пересэмплированием целых дебютных семейств: обе
цветовые партии и игры всех участников сохраняются вместе. По распределению
рейтинга Zenith получается percentile 95% interval.

Этот интервал условен относительно закреплённого рейтинга соперника.
Он не включает погрешность самого CCRL-якоря и различие условий. Отдельно
сохраняются оценки при переносе точки отсчёта на каждого другого соперника;
их разброс показывает чувствительность к выбору опоры. Несогласованные опоры
нельзя превращать в утверждение о «точном Elo».

```powershell
.venv-nnue/Scripts/python.exe -u tools/run_rating_gauntlet.py --out runs/zenith-rating-20261027
```

Состояние — status.json, выбор соперников — scouts.json / selected.json.
Итог — rating.json, ratings.txt / ratings.csv, bootstrap.json и rated-games.pgn.
Исходные партии и манифест каждого матча сохраняются отдельно. Ни текущие
веса, ни новый рейтинг не устанавливаются автоматически в доску анализа.

## Возобновление после ошибки формата MinimalChess

Первая основная серия с MinimalChess 0.6 остановилась на `bestmove b7b8Q`:
Fastchess требует строчный суффикс превращения. По сохранённому PGN ход
`b7b8q` легален в позиции `5k2/1P6/6P1/5K2/8/8/8/8 w - - 3 88`.
Все партии незавершённой серии исключены; готовые серии Topple и Weiss
сохраняются, новая попытка MinimalChess проходит полные 96 цветовых пар.

`examples/uci_normalize.rs` запускает исходный бинарник и переводит только
суффиксы QRBN координатных ходов в `bestmove` и `info` в нижний регистр.
Команды, поиск, выбор хода, оценки и параметры соперника не меняются.
Исходный бинарник остаётся побайтно прежним; обе части запуска адаптера
добавляются в замороженные SHA-256. Исходный план сохраняется отдельно,
поправка протокола записывается в `compatibility_amendments`.

```powershell
cargo build --locked --release --example uci_normalize
.venv-nnue/Scripts/python.exe -u tools/run_rating_gauntlet.py --out runs/zenith-rating-20261027 --resume --normalize-minimalchess-promotions --seconds 6600
```
