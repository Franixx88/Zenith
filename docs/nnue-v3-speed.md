# Ускорение NNUE v3: маски нулевых входов и общие обновления

На обученной сети `576258170751…` медиана `bench 8` уменьшилась с
1671648 до 1402909 мкс: **−16.1% времени, +19.2% NPS**. Во всех повторах
совпали 622292 узла, оценки, лучшие ходы и все поисковые счётчики.
Микробенч delta+head: **1602.6 → 952.7 нс**, −40.6% времени;
refresh+head: 2966.5 → 2420.0 нс, −18.4%.

Это замер скорости конкретной обученной сети на локальном Ryzen 5 2400G,
а не прирост Elo. Пять запусков каждой сборки чередовались в прямом и обратном
порядке; использованы одинаковые веса и фиксированные позиции.
[Полные замеры, выводы и SHA-256 бинарников](benchmarks/nnue-v3-speed-20261027.json).

## Изменения

На загрузке создаются неизменяемые упакованные матрицы скрытых слоёв:
плитка из 16 выходных нейронов, внутри — пары входов. Упаковка добавляет
139264 байта на всю сеть и разделяется всеми потоками. Формат файла и
параметры модели сохраняются; переобучение для ускорения не требуется.

AVX2 получает две активации сразу для 16 выходов. Восемь пар проверяются
одной маской, затем вычисляются только ненулевые пары. Это убирает
непредсказуемое ветвление на каждой паре и повторное чтение одних активаций
отдельно для каждого нейрона. Используется `madd_epi16` с i32-накоплением;
результаты не зависят от насыщения промежуточных i16-произведений.
Отрицательные суммы после сдвига всё равно отсекаются в ноль, поэтому
результат совпадает с прежним знаковым делением на 64 и clamp.

Обычный ход, взятие, EP, превращение и рокировка теперь обновляют
512-нейронную перспективу за один проход: все удаления, затем все добавления,
с одним чтением и записью сумм. Разности фигур собираются один раз для обеих
перспектив. При смене королевского контекста нужная перспектива пересчитывается;
для произвольных FEN resets сохранён общий путь обработки всех изменений.

Scalar reference использует исходные output-major матрицы и отдельные
скалярные произведения. V1/v2 продолжают использовать прежние кадры и ядра.
В совместимом v1-бенче совпали все 533368 узлов и счётчики; по этому короткому
шумному замеру отдельного заявления об изменении её скорости нет.

## Воспроизводимость и проверки

```powershell
.venv-nnue/Scripts/python.exe tools/bench_nnue_speed.py --baseline runs/v3-speed-20261027/baseline.exe --baseline-nnue runs/v3-speed-20261027/baseline-nnue.exe --candidate target/release/zenith.exe --candidate-nnue target/release/examples/nnue.exe --network networks/zenith-v3-576258170751.znnue --out runs/v3-speed-20261027/final-bench.json --repeats 5
```

Скрипт отвергает сравнение при различии inference checksum или любых данных
поиска, кроме времени/NPS. Каждый запуск создаёт новый процесс; оба режима
оценки используют один и тот же воспроизводимый проход по 1024 доскам.
Замер исключает movegen из inference и включает его в полноценный search bench.

Прошли 166 Rust-тестов (`--all-targets`), 7 специальных тестов помечены ignored;
Clippy `-D warnings` и форматирование чистые. Добавлена независимая проверка
плиточных слоёв на плотных/разреженных входах и численных границах. Проверены
также превращения со взятием обоих цветов, EP, рокировки, undo, mirror crossings,
arbitrary resets, SMP/MultiPV и смена модели во время работы.

На 2048 позициях совпали trainer integer, checkpoint QAT CUDA, NumPy,
Rust scalar/AVX2, delta, refresh и dense. Веса совпадают с лучшим checkpoint
эпохи 24: `576258170751e54bbf6c0e7729cbe432168fdbc474a27a4f67e1214a7f4891d9`.
Локальные журналы — `runs/v3-speed-20261027/rust-tests.log` и `parity.log`.

## Обученная сеть и длинный матч

Завершены все 24 эпохи, 201326592 предъявления. Loss лучшей сети —
0.00944126345, против 0.01084087076 у первой v1 на том же validation.
До ускорения короткий матч 128 партий, 5s+0.05s, завершился **+46 =29 −53**:
уверенного игрового преимущества v3 не установлено.
[Манифест сети](../networks/layered-control-20261027.json),
[партии короткого матча](../games/zenith-nnue-v3-holdout-20261027.pgn).

Следующий контроль использует ускоренный бинарник с обеих сторон, v3 против
стабильной v1, **128 пар / 256 партий, 15s+0.15s**, Threads=1, concurrency=4,
Hash=32 MiB, Move Overhead=50 ms. Syzygy и Context Histories выключены,
holdout-дебюты, seed=20261027. Предел — 7200 секунд бодрствования системы.

```powershell
.venv-nnue/Scripts/python.exe -u tools/nnue/run_v3_match.py --out runs/v3-long-control-20261027
```

Контроллер фиксирует копии бинарника и весов, SHA-256, коммит, параметры,
статус и журналы. Достоверным результатом считается только полный матч,
прошедший независимую проверку PGN; его summary появится в `match/summary.json`.
Сеть остаётся экспериментальной до анализа результатов.
